# BrajMart Shipping Label Generator

A React frontend with a Node.js, Express, MongoDB backend for creating, tracking, and printing shipping labels.

## Development

You need Node.js, npm, and MongoDB running locally or a MongoDB Atlas URI.

```sh
npm --prefix frontend i
npm --prefix backend i
copy backend\.env.example backend\.env
cd frontend
npm run dev
```

Frontend: http://localhost:8080
Backend: http://localhost:5000
